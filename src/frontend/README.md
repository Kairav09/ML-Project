# Demand AI — Product Demand Forecasting Frontend

Expo demo frontend for the ML course project
**"Product Demand Forecasting Using Ridge and Lasso Regression"**.

This is a React + Vite adaptation of the expected "Results – Frontend" layout
(Login, Dashboard, Prediction, Live Demand, Reports, Settings).

## The prediction is real

The Prediction page runs your **actual trained Lasso model in the browser**
(`src/lib/predict.js`) — it replicates the `final.ipynb` pipeline exactly:

- Date → Year/Month/Day/DayOfWeek (Mon=0), `Is_Weekend`, `Promo_Or_Holiday`
- One-hot `Warehouse` / `StateHoliday` / `Product_Category` (drop_first, same as `pd.get_dummies`)
- `Product_Code` target encoding (train means, global-mean fallback for unseen products)
- `StandardScaler` on Year, Month, Day, DayOfWeek, Petrol_price, Product_Code_TargetEnc
  (plus the legacy full-data `Petrol_price_scaled` from the notebook)
- Lasso dot product + intercept (α = 0.336, test R² = 0.327)

Verified: JS predictions match the Python pipeline to the decimal on test inputs.

## Run it

```bash
cd demand-ai
npm install
npm run dev
```

Open **http://localhost:3000** — log in with any email/password (mock auth),
then screenshot each page for your presentation slide.

## Pages

| Page | What it shows |
|---|---|
| Login | Split-screen login / register (mock auth) |
| Dashboard | 4 stat cards, Demand by Warehouse, 30-day trend, top categories, model summary |
| Prediction | Product/warehouse/category/date/promo/holiday inputs → live Lasso prediction + key drivers |
| Live Demand | Searchable table of recent demand records with Low → Very High badges |
| Reports | Date-range demand report: totals, peak day, flow chart, top categories |
| Settings | Profile, alert toggles, model information card |

## Data

`src/data/model.json` — exported Lasso artifacts (features, coefficients,
scalers, target-encoding map). `src/data/app-data.json` — dashboard aggregates,
daily series, dropdown options. Generated by `export_model.py` from
`data/Retail_Dataset.csv`; re-run it if the notebook changes.
